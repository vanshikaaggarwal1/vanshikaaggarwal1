## 🚀 What I'm Building

### ⚡ WorkSync — Workflow Management System

A full-stack workflow management platform designed to help teams organize projects, tasks and productivity.

**Key Features**

* 🔐 JWT-based authentication
* 👥 Role-based access
* 📋 Task creation & assignment
* 📊 Productivity dashboards
* 🔔 Notifications
* 🤝 Team collaboration
* 🎨 Responsive React + Tailwind interface

**Stack:** `React` `Tailwind CSS` `Node.js` `Express.js` `MongoDB`

---

### ☀️ Solar Panel Efficiency Monitoring

A web-based system designed to monitor and analyze solar panel performance.

**Key Features**

* 📊 Performance monitoring
* ⚡ Power generation analysis
* 📈 Efficiency calculations
* 🚨 Alerts & maintenance tracking
* 📑 Reports and analytics
* 👤 User-specific panel data

**Stack:** `React` `Node.js` `Express.js` `MongoDB` `Chart.js` `JWT`

---

### 📡 Noise Monitoring System

An IoT-based monitoring system that measures environmental noise and displays real-time data through a web dashboard.

**Hardware:** `ESP32` `KY-038` `LCD`

**Software:** `Firebase` `React` `Chart.js`
